RG&D - NS Enhancements Privacy Policy

Effective and last updated: October 3, 2026

Overview

The RG&D - NS Enhancements extension for Microsoft Edge processes information locally in the browser to provide its user-facing features. Reliant Group does not receive, sell, or transmit NetSuite page content or user editing activity.

Purpose and scope

This policy applies to the RG&D - NS Enhancements extension for Microsoft Edge. The extension improves the usability and safety of supported NetSuite pages by keeping important information visible, identifying incomplete required fields, distinguishing Sandbox accounts, and showing changes made during the current editing session.

Information processed locally

The extension handles the following information only as needed to provide its features:

  • Website content: NetSuite page structure, field labels, field values, required-field indicators, record headers, and transaction sublist tables.
  • User activity: Input, change, and focus events used by the required-fields tools and session change tracker.

This processing occurs within the active NetSuite browser page. Field values used by the session change tracker remain in page memory and are discarded when the page is refreshed, closed, or unloaded.

Information stored

The extension stores only feature enablement preferences and an internal settings version through the Microsoft Edge extension storage sync API. It does not place NetSuite record content, field values, credentials, or browsing history in extension storage.

If Microsoft Edge browser sync is enabled, Microsoft Edge may synchronize these non-content preferences under the user's browser profile. Reliant Group does not operate the browser sync service and does not receive this preference data.

Information not collected by Reliant Group

The extension does not transmit NetSuite page content or user editing activity to Reliant Group or any third party. It does not use analytics, advertising, tracking pixels, external services, or remote code. It does not intentionally target, classify, persist, or transmit personally identifiable information, health information, financial or payment information, authentication information, personal communications, location, or web history.

Sharing and sale of information

Reliant Group does not sell, license, transfer, or share NetSuite page content or user editing activity with third parties. Data handled by the extension is used only to provide the extension's disclosed functionality.

User controls and retention

  • Users can enable or disable each enhancement from the extension popup.
  • Users can disable all enhancements with the master control.
  • Session change information is discarded when the current NetSuite page session ends.
  • Feature preferences remain until the user changes them, clears extension data, disables browser sync, or removes the extension.
  • Users can remove the extension through Microsoft Edge at any time.

Permissions

  • Storage: Saves feature preferences and the internal settings version.
  • NetSuite host access: Allows the packaged content script and stylesheet to provide the extension's features on supported NetSuite pages. The extension does not run on unrelated websites.

Policy changes

This policy may be updated when the extension's features or data-handling practices change. The latest version will remain available at this URL, and its effective date will be updated when material changes are made.
